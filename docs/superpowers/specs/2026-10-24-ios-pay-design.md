# シフト管理 iOS: 給与計算(時給・交通費・加給・深夜・残業・休憩ルール) 設計書

ユーザーの決定に基づく。Web版にはない iOS 独自の機能。

## ユーザー決定事項
- 職場ごとに、時給、交通費、曜日ごとの加給、祝日の加給、休憩ルールを設定する
- 加給は **時給への上乗せ(+X円/時)**。曜日(日〜土)ごとに設定。祝日は曜日より優先し、重ねない(祝日なら祝日加給のみ。曜日加給は付けない)。加給は予定の開始日で判定する(週計・月計が開始日で数える規則と同じ)
- 交通費は職場に **片道** の金額を入力し、**1予定ごとに往復(×2)** で加算する(実労働が0の予定、終日の予定は除く)
- 深夜割増は **22:00〜翌5:00 の実労働に +25%**(法定)。固定値で編集不可
- 残業割増は **1予定の実労働が8時間(480分)を超えた分に +25%**(固定)。深夜と重なる部分は割増が合算されて +50% になる(両方の割増を独立に足す)
- 休憩: 無給として拘束時間から引く。深夜帯を含む予定で休憩があるとき、**休憩を深夜帯から引くか、深夜以外から引くか**を予定ごとに選べる。既定値は職場の設定に持ち、**職場設定の既定は「深夜帯から引く」**
- 休憩ルール: 職場ごとに「◯時間 **以上** / ◯時間 **を超える**」(プルダウンで選択)と、その休憩分数の組を複数設定できる。設定がない職場は法定どおり(**6時間を超える → 45分、8時間を超える → 60分**)

## データモデル(すべて Optional か既定値つき。既存データと互換)
- `ShiftEvent` に追加: `workplaceId: String?`(職場の選択で設定)、`breakInNight: Bool?`(nil なら職場の既定に従う。true = 休憩を深夜帯から引く)
- `Workplace` に追加(旧データの読み込みは既定値で補う): `hourlyWage: Int = 0`、`transport: Int = 0`、`weekdayBonus: [Int] = [0,0,0,0,0,0,0]`(添字0=日曜〜6=土曜、円/時)、`holidayBonus: Int = 0`(円/時)、`breakRules: [BreakRule] = []`、`breakFromNight: Bool = true`
- `BreakRule: Codable, Equatable, Identifiable`: `id: String`、`hours: Double`(しきい値の時間数)、`comparison: BreakComparison`(`.atLeast` = 以上、`.over` = を超える)、`minutes: Int`(休憩分数)
- 予定の職場の解決: `workplaceId` が職場に一致すればその職場。なければ、タイトルが職場名と完全一致する職場。どちらもなければ職場なし(給与は計算しない。休憩の既定は法定)

## 計算(純粋関数、`Core/` に置く)
### 休憩の既定(`BreakRules`)
- `BreakRules.minutes(span: Int, rules: [BreakRule]) -> Int`: `span` は拘束時間(分)。`rules` が空なら法定: `span > 480` → 60、`span > 360` → 45、それ以外 0。`rules` があれば、満たすルール(`.atLeast`: `span >= hours*60`、`.over`: `span > hours*60`)のうち **しきい値(hours)が最大のもの** の分数。満たすルールがなければ 0。しきい値が同じなら配列の後ろのものを採用
- `Rules.workHours(...)` と `Rules.defaultBreak` は法定のまま残す(既存テストと、職場なしの予定が使う)
- 休憩の実際の分数: 予定に `workHours` が保存されていれば `span - workHours*60`(四捨五入)、なければ上の既定

### 給与(`PayCalculator`)
`PayCalculator.pay(event: ShiftEvent, workplace: Workplace, isHoliday: Bool) -> PayBreakdown?`
- 終日の予定、時刻がない予定、実労働が0以下の予定は `nil`
- `S` = 拘束時間(分、`Rules.totalMinutes`)、`B` = 休憩の実際の分数(上記)、`W = S - B`(0以下なら `nil`)
- 夜間の重なり: 開始時刻 `s`(分)から `[s, s+S)` が、深夜帯 `[0,300)`、`[1320,1740)`、`[2760,3180)`(分。22:00〜翌5:00を日をまたいで3区間)と重なる分数を `N`。日中 `D = S - N`
- 休憩の割り当て: `fromNight = event.breakInNight ?? workplace.breakFromNight`。`fromNight` なら、まず夜間 `N` から `min(B, N)` を引き、残りを日中から引く。そうでなければ先に日中 `D` から引き、残りを夜間から引く。結果を正味の夜間 `Nn`、正味の日中 `Dn`(`Nn + Dn == W`)
- 残業 `O = max(0, W - 480)`
- 加給の単価: `isHoliday ? workplace.holidayBonus : workplace.weekdayBonus[曜日(開始日)]`(曜日は `Rules.weekday`、日曜=0)
- 金額(円、Double):
  - `base = W/60 × hourlyWage`
  - `night = Nn/60 × hourlyWage × 0.25`
  - `overtime = O/60 × hourlyWage × 0.25`
  - `bonus = W/60 × 加給の単価`
  - `transport = 片道 × 2`(`workplace.transport` は片道。往復で計算)
  - `total = base + night + overtime + bonus + transport`
- `PayBreakdown { base, night, overtime, bonus, transport, total: Double; netMinutes: Int; nightMinutes: Int; overtimeMinutes: Int }`

### テスト値(そのまま期待値に使う)
時給1000円、交通費(片道)250円、加給なし、休憩ルールなし(法定)の職場で:
- 09:00〜18:00(`S=540`, `B=60`, `W=480`)、昼間: `base=8000`、`night=0`、`overtime=0`、`bonus=0`、`transport=500`(250×2)、`total=8500`
- 22:00〜翌06:00(`S=480`, 法定 `B=45`, `N=420`): 休憩を深夜から引く → `Nn=375`, `Dn=60`, `W=435`: `base=7250`、`night=1562.5`、`total=7250+1562.5+500=9312.5`。休憩を深夜以外から引く → `Dn=15`, `Nn=420`: `base=7250`、`night=1750`、`total=9500`
- 09:00〜20:00(`S=660`, `B=60`, `W=600`, `O=120`): `base=10000`、`overtime=500`、`total=11000`
- 祝日加給100円/時の職場で 09:00〜18:00、祝日: `bonus=800`。日曜加給50円/時・祝日加給100円/時 で祝日が日曜のとき: `bonus=800`(祝日優先、重ねない)
- 休憩ルール `[以上 6時間→30分, 超える 8時間→90分]` の職場: `S=360` → 30分(6時間以上を満たす)、`S=361` → 30分、`S=480` → 30分(8時間を超えないため)、`S=481` → 90分、`S=359` → 0分。`rules=[]` で `S=480` → 45分、`S=481` → 60分、`S=360` → 0分、`S=361` → 45分
- 終日の予定 → `nil`

## 表示
- 集計の帯(`SummaryStrip`): 色グループごとのチップを `● タイトル 8h ¥8,500` の形にし、合計は `合計 8h ¥8,500`。給与が0円のグループ(職場なし、時給未設定)は円を出さない。合計に給与が1つもなければ円を出さない
- 予定の編集画面: 職場が選ばれていて時間ありの予定では、`見込み給与 ¥9,313` と内訳(基本・深夜割増・残業割増・加給・交通費(往復))を表示する
- 金額は円単位に四捨五入して `¥` とカンマ区切りで表示(`NumberFormatter`、日本ロケール)。合計は未四捨五入の値を足してから丸める

## 設定画面(職場の編集シート)
- 名前、色(既存)に加えて: 時給(円)、交通費(片道、円。「1予定ごとに往復(×2)で計算します」と注記)、曜日別の加給(日〜土、円/時)、祝日の加給(円/時)、休憩ルール(行ごとに [以上|を超える]のプルダウン + 時間 + 休憩の分数、追加と削除。ルールがなければ「設定がなければ法定(6時間超45分、8時間超60分)」と案内)、休憩を引く時間帯の既定(プルダウン: 深夜帯から / 深夜以外から。既定は深夜帯)
- 金額と時間はすべて数字キーボード。キーボードの上に「完了」ボタン

## 予定の編集画面
- 職場のチップを選ぶと `workplaceId`、タイトル、色が入る。タイトルは編集できる(リンクは `workplaceId` で保つ)。別の職場を選ぶと付け替える。職場の選択を外す手段として「職場なし」チップを先頭に出す
- 休憩の既定(プレースホルダー、リセットで戻る値)は、選択中の職場の休憩ルールから決める
- 時間あり・深夜帯を含む・休憩が1分以上あるとき、`休憩を引く時間帯` のプルダウン(職場の既定に従う / 深夜帯から / 深夜以外から)を出す。選んだ値は `breakInNight` に保存する(「職場の既定に従う」は nil)
- 保存時の `workHours` は、選択した職場の休憩ルールで既定の休憩を決めて計算する(手入力の休憩があればそれを優先)

## スコープ外
- 締め日・支払日、月をまたぐ集計、給与明細の出力、所得控除(税・社会保険)、複数職場の合算の内訳画面

## 締め日・給料日
- 職場の編集シートに「給料日」セクションを追加: 締め日(末日 / 1〜31日のプルダウン)、「給料日を設定する」トグル。オンのとき支払い月(当月 / 翌月 / 翌々月)と給料日(末日 / 1〜31日)を選ぶ。新規の既定は末日締め・給料日オフ。初めてオンにすると翌月25日になる。例: 末日締め・翌月25日払い
- 給料日の日付セル(月表示は日付の行の右端、週表示は日のヘッダーの右上)に、重なった2枚のコインのアイコンを出す。セルの予定追加のタップとは別に、アイコンのタップで給料シートを開く
- 給料シート: 「M/d の給料」。その日が給料日の職場ごとに、職場の色、名前、対象期間(締め日で終わる期間、例 10/1〜10/31)、金額を出し、最後に合計を出す。該当する職場がなければ「この日に給料が入る職場はありません」。色フィルタは無視する

## 集計の表示
- ヘッダーの「週計」ボタンで週ごとの帯(月表示は各週の下、週表示は下部)を出し入れする。オンにすると未配置エリアを畳み、オフで元に戻す
- 「月計」は常に表示する(月表示は下部の固定帯、週表示は週計の下)
- 集計の帯は時間だけを表示する(`● タイトル 8h`、`合計 8h`)。金額は給料シートと、予定の編集画面の見込み給与に出す
