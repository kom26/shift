# iOS 拡張時間(24時超え表記)設計

## 入力範囲
- 開始時刻: 00:00 〜 27:00、終了時刻: 00:00 〜 36:00("HH:mm" 文字列)。
- 例: 29:00 = 翌実日の 05:00、25:00 = 翌実日の 01:00。

## 表示規則
- 月ビュー: 開始または終了が 24:00 以降の予定は開始日のみの単日バー(`resolveEndDate` は開始日を返す)。通常の日またぎ(例 22:00→06:00)は従来どおり終了日 = 開始日+1。比較は分の数値で行う。
- 週ビュー: 実時間で表示。`timedSegment` が開始日 0:00 からの分 [s, e) を表示日の範囲と交差させる(最小高さ30分、日の下端でクランプ)。
- 集計・給与: 開始日で集計。継続時間は実分数(`totalMinutes`)。深夜帯は 0-300 / 1320-1740 / 2760-3180 分。

## 入力 UI(EventEditor)
- 終日オフ時、「開始」「終了」の2行。右側に日付チップと時刻チップ。
- 時刻チップをタップすると直下にホイール(時 0...27 / 0...36、分 5分刻み)を開く。同時に開けるのは1つ。
- 隠し数字TextFieldでテンキー入力も併用。4桁入力で検証(`parseTimeDigits(_, maxMinutes:)`)し即反映、不正は触覚エラーで破棄。チップには入力途中を表示。
- 5分刻みでない既存値はホイールに追加項目として保持。27:00 / 36:00 では分は 00 のみ。
- 翌日またぎヒントは 終了 <= 開始 かつ 終了 < 24:00 のときのみ。
- キーボードの「完了」でキーボードとパネルを閉じる。
