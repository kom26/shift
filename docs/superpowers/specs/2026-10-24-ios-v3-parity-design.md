# シフト管理 iOS v3: Web版との機能パリティ 設計書

Web版 `index.html` を正とし、`2026-10-24-web-feature-inventory.md`(85項目の差分表)の ❌/⚠️ を埋める。
v1 設計書、v2 設計書の続き。

## ユーザー決定事項
- 入れる: 予定の複製(長押しメニュー)、一括取り込み
- 入れない: バー端のドラッグによる終了日リサイズ、未配置の手動並べ替え、初回サンプルデータ、キーボードショートカット(スマホでは対象外)、PCサイドバーの開閉
- 色フィルタ: 現状どおり(選んだ色の予定はカレンダーにも表示し、他の色は隠す。集計も同じ色だけ)
- ヘッダーの「＋追加」: 未配置の予定を作る(Web版と同じ)

- 職場の登録: 設定で職場を名前と色で登録しておき、予定作成時にタイトルを自由入力するか職場の一覧から選べる。職場は「タイトルと色のプリセット」で、予定との紐づけは持たない(データモデル不変)。職場の名前・色を変えるときは、タイトルが一致する既存予定にも反映するか確認する

## 不具合の修正(ユーザー報告)
1. 予定をドラッグしたときの持ち上げプレビューが、指と離れた位置に浮く。`.offset` の後に `.draggable` を付けているため、プレビューが offset 前の位置から作られている。ドラッグ元は offset の前に付けるか、`.position` で配置する
2. ドラッグ中にプレビューの「+」が出る。`dropDestination` はコピー扱いになる。`onDrop(of:delegate:)` の `DropDelegate` で `DropProposal(operation: .move)` を返す
3. 予定を開いたときの日付が英語表記。アプリのローカライズが英語のため。`DEVELOPMENT_LANGUAGE: ja` と、ルートで `.environment(\.locale, Locale(identifier: "ja_JP"))` を設定する
4. 最下部がセーフエリアに未対応。未配置エリアの背景をホームインジケータの下まで伸ばし、内容はセーフエリア内に置く
5. 週計が最終週(アンカー週)の1つしか出ない。月表示では各週の行ごとに週計を出す(Web版 M14)
6. 月の前後(1日より前、月末より後)の日が空白。隣接月の日付と予定を表示し、タップ・ドラッグ配置も同じようにできる(Web版 M2)

## Web版との差分を埋める仕様(差分表のID)
- 月ビュー: 行は予定の段数に合わせて伸び、全体はスクロールする(M7)。バーは「色の16%背景+色の文字」で、時間あり=`HH:MM〜HH:MM`、終日・時間なし=タイトル、継続セグメントは「…」(M5, M6)。今日のセルは背景を淡く着色(M4)。祝日名はセルに出さない(M3、Web版のモバイルと同じ)。ドロップ先のセルをハイライト(M11)
- 週ビュー: 毎正時の時刻ラベルと30分の補助線(W3)、週ヘッダーに祝日名(W1)、時間ブロックは色80%の塗りと白文字で大きめの文字(W5)、現在時刻線(W7)、終日行の空白タップで追加、終日行もドロップ先(W2)、ドロップ先の列をハイライト(W9)
- 集計: 週計(モード1)= 月ビューは各週の行の下に、週ビューは画面下に、チップ(色の点・タイトル・時間)と「合計」を出す。空は月ビューで「-」、週ビューで「データなし」。月計(モード2)= 月ビューは画面下に1本、週ビューには出さない(Web版と同じ)(M14, M15, M16, W10)
- ヘッダー(Web版のモバイルと同じ構成): 1行目 = ☰、‹ タイトル ›、＋追加。2行目 = 週/月、今日、日始/月始、集計(集計→週計→月計)、CSV(H5, H6, H7, H8, H10)
- ☰ドロワー(シート): 月集計パネル(色ごとのチェックボックス=色フィルタ、配置済/未配置の実労働時間)、予定リスト(配置済は開始日順、未配置は後)、「＋予定を追加」「一括取り込み」「設定」(SB1, SB3, SB4, SB5, SB6)。現在の色フィルタ用シートは廃止
- CSV: Web版と同一(列・並び・BOM・ファイル名 `shifts_YYYYMM.csv`)。共有シートで出す(C1, C2)
- 一括取り込み: Web版と同一の形式(タブ区切り2列、1行1予定)。プレビュー、色選択、`N件取り込む`(B1〜B3)。クリップボードから貼り付けるボタンを付ける
- 予定の複製: チップ・バー・ブロックの長押しメニューに「複製」「編集」「未配置に戻す」「削除」(M13の代替)
- エディタ: 休憩の「リセット」ボタン(E9)
- 未配置エリア: 空状態に 🎉、回収の確認文は `YYYY年M月`、チップ領域の背景も「未配置に戻す」の受け先にする(U3, U6, U9)
- ダークモードのアクセント色は `#818cf8`(P4)

## 設計の方針
- 集計・CSV・一括取り込みの解釈は `Core/` の純粋関数にしてテストする(Web版の挙動を期待値にする)
- ドラッグ&ドロップの受け口は `Views/Calendar/EventDropDelegate.swift` に共通化する(列/日付の解決をクロージャで渡す)
- 計算に必要な境界は `Rules.monthGrid`(隣接月を含む全日付の月グリッド)で提供する
- 既存の `monthWeeks`(空白あり)は残す(既存テストが使用)
